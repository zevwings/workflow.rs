# 中文内容统一规范

## 适用范围

| 纳入 | 排除 |
|------|------|
| CLI 输出、错误消息、交互提示、帮助文本 | 代码注释、文档、内部调试日志 |

---

## 内容分类

1. **错误消息**：`#[error(...)]`、`format!` 等用户可见异常
2. **CLI 文案**：命令 about、参数 help、验证失败提示
3. **交互提示**：选择、输入、确认等表单文案
4. **示例与测试**：examples、tests 中的用户可见输出（风格与主程序一致）

---

## 术语规范

| 英文 | 中文 |
|------|------|
| branch | 分支 |
| commit | 提交 |
| repository | 仓库 |
| setup | 配置 / 初始化 |
| dry run | 预览 / 试运行 |
| Jira / GitHub / Pull Request | 产品名保留原文 |

---

## 句式规范

- **错误消息**：问题描述 + 可选原因/建议
- **帮助文本**：动词开头（如「显示版本信息」）
- **交互提示**：以冒号结尾（如「选择源分支：」）
